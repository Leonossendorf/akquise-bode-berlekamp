# Entwurf: Bode | Berlekamp Steuerberater (Neuenkirchen) und Schaper & Partner (Metelen)

Unverbindlicher Website-Entwurf von Leon Oßendorf (Webdesign, leonossendorf.de). Kein offizieller Auftritt der Kanzlei. `noindex`, `robots.txt` sperrt alles.

- Zwei Designs mit Schalter im Banner: `?design=nuss` („Steuernuss“) und `?design=klar` („Klar“). Ohne JavaScript gilt „Klar“.
- Statisch: HTML, `css/base.css` + `css/klar.css` + `css/nuss.css`, `js/design.js` (Design vor dem Rendern), `js/main.js` (Standort, Status, Formulare als Demo).
- Schriften lokal (`fonts/`), keine Cookies, keine fremden Dienste.
- Bildquellen in `img/QUELLEN.txt`.
- Die Seiten werden aus `Bode-Berlekamp/tools/build.py` (außerhalb des Repos) erzeugt.
